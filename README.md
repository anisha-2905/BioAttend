
# BioAttend — Biometric Smart Attendance System

BioAttend is a B.Sc. Information Technology project that combines fingerprint-based attendance recording with a web-based attendance management system.

## Features

- Fingerprint enrollment and verification
- ESP32 and R307S fingerprint sensor integration
- Flask-based backend
- PostgreSQL database
- Admin, Teacher, and Student modules
- Attendance records and reporting
- Authentication and biometric-template encryption

## Technology Stack

- Python and Flask
- PostgreSQL
- HTML, CSS, and JavaScript
- ESP32 and Arduino C++
- R307S fingerprint sensor

## Project Status

Academic project developed as part of the B.Sc. Information Technology programme.
